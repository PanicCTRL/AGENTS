# Функции для работы с метками (Labels)

Предназначены для программного создания, удаления и настройки графических меток на диаграммах терминала QUIK.

---

## AddLabel
Добавляет метку на график.

**Формат вызова:**
```lua
NUMBER id = AddLabel(STRING chart_tag, TABLE label_params)
```

**Параметры:**
- `chart_tag` — строковый идентификатор (тег) графика.
- `label_params` — таблица с настройками метки.

**Возврат:** Числовой идентификатор метки (`id`) или `nil` при ошибке.

### Таблица параметров метки (`label_params`)
| Параметр | Тип | Описание |
|----------|-----|----------|
| **TEXT** | STRING | Текст подписи метки. |
| **IMAGE_PATH** | STRING | Путь к файлу картинки (*.bmp, *.jpeg). Пусто, если картинка не нужна. |
| **ALIGNMENT** | STRING | Положение картинки относительно текста: `LEFT`, `RIGHT`, `TOP`, `BOTTOM`. |
| **YVALUE** | DOUBLE | Значение по оси Y (цена), к которому привязана метка. |
| **DATE** | DOUBLE | Дата в формате `ГГГГММДД`. |
| **TIME** | DOUBLE | Время в формате `ЧЧММСС`. |
| **R, G, B** | DOUBLE | Компоненты цвета текста (0–255). |
| **TRANSPARENCY** | DOUBLE | Прозрачность всей метки (0–100%). |
| **TRANSPARENT_BACKGROUND** | DOUBLE | Прозрачность фона картинки: `1` — вкл, `0` — выкл. |
| **FONT_FACE_NAME** | STRING | Название шрифта (например, "Arial"). |
| **FONT_HEIGHT** | DOUBLE | Размер шрифта. |
| **HINT** | STRING | Текст всплывающей подсказки при наведении. |

## DelLabel
Удаляет конкретную метку.

**Формат вызова:**
```lua
BOOLEAN res = DelLabel(STRING chart_tag, NUMBER label_id)
```
Возвращает `true` при успехе.

---

## DelAllLabels
Удаляет сразу все метки с указанной диаграммы.

**Формат вызова:**
```lua
BOOLEAN res = DelAllLabels(STRING chart_tag)
```

---

## GetLabelParams
Позволяет получить текущие параметры существующей метки.

**Формат вызова:**
```lua
TABLE params = GetLabelParams(STRING chart_tag, NUMBER label_id)
```

> **Важно:** В возвращаемой таблице все ключи указаны в **нижнем регистре** (например, `text`, `yvalue`), а все значения приведены к типу **STRING**.

---

## SetLabelParams
Изменяет параметры уже созданной метки.

**Формат вызова:**
```lua
BOOLEAN res = SetLabelParams(STRING chart_tag, NUMBER label_id, TABLE params)
```
В таблице `params` указываются только те поля, которые нужно изменить.
