# Индикаторы технического анализа на Lua

Индикаторы — это особый класс скриптов QUIK, которые работают внутри графического модуля. Они позволяют отрисовывать пользовательские линии (MA, RSI и др.) на графиках цен.

---

## 1. Общие сведения
- **Расположение**: Скрипты должны находиться в папке `LuaIndicators` в каталоге терминала.
- **Машина Lua**: По умолчанию используется версия **5.3.5**.
- **Требования**: Файл должен содержать:
  1. Таблицу `Settings` с полем `Name`.
  2. Функцию `Init()`.
  3. Функцию `OnCalculate()`.

---

## 2. Жизненный цикл индикатора

### Init()
Вызывается при добавлении индикатора на график.
**Возврат:** NUMBER — количество линий, которые будет отрисовывать индикатор.
```lua
function Init()
    return 1 -- Индикатор будет рисовать одну линию
end
```

### OnCalculate(index)
Вызывается при поступлении новой свечи или изменении текущей.
**Параметры:** `index` — номер свечи (начинается с 1).
**Возврат:** Значение (или несколько значений через запятую) для каждой линии на данном индексе.
```lua
function OnCalculate(index)
    return C(index) -- Рисует линию по ценам закрытия
end
```

### OnDestroy()
Вызывается при удалении индикатора или закрытии окна графика. (Необязательна).

### OnChangeSettings()
Вызывается, когда пользователь изменил параметры индикатора в диалоговом окне настроек.

---

## 3. Доступ к данным графика
Внутри индикатора доступны глобальные функции для быстрого доступа к свечам текущего графика:

| Функция | Описание |
|---------|----------|
| `O(i)` | Цена открытия свечи `i`. |
| `H(i)` | Максимальная цена (High). |
| `L(i)` | Минимальная цена (Low). |
| `C(i)` | Цена закрытия (Close). |
| `V(i)` | Объем свечи. |
| `T(i)` | Время свечи (в формате таблицы `datetime`). |
| `Size()` | Общее количество свечей в источнике. |
| `CandleExist(i)` | Проверка: существует ли свеча (не пустой ли это интервал). |

---

## 4. Подключение внешних библиотек
Для сложных расчетов рекомендуется выносить логику в отдельные файлы и подключать их в начале скрипта индикатора:
```lua
dofile(getWorkingFolder() .. "\\Include\\my_math_lib.lua")
```
Это позволяет повторно использовать код в разных индикаторах.

---

## 5. Управление значениями линий
В индикаторах можно не только возвращать значения из `OnCalculate`, но и принудительно устанавливать их на любой свече.

| Функция | Описание |
|---------|----------|
| `SetValue(idx, line, val)` | Устанавливает значение `val` для линии `line` на свече `idx`. |
| `GetValue(idx, line)` | Получает значение линии `line` со свечи `idx`. |
| `SetRangeValue(line, start, end, val)` | Заполняет интервал свечей от `start` до `end` значением `val`. |

> **Пример:** `SetValue(index-1, 1, 150.5)` — изменить значение предыдущей свечи.

## 5. Настройка таблицы `Settings`
Таблица `Settings` определяет, как индикатор выглядит и какие параметры видит пользователь.

### Системные поля линий (`Settings.line[n]`)
- **Name**: Название линии в легенде.
- **Color**: Цвет (через `RGB(r, g, b)`).
- **Width**: Толщина линии.
- **Type**: Тип отрисовки. Доступные константы:
  - `TYPE_LINE` — сплошная линия.
  - `TYPE_HISTOGRAM` — гистограмма.
  - `TYPE_POINT` — точки.
  - `TYPE_DASH` / `TYPE_DASHDOT` — штрихи и пунктиры.
  - `TYPE_TRIANGLE_UP` / `TYPE_TRIANGLE_DOWN` — треугольники.
  - `TYPE_CANDLE` / `TYPE_BAR` — свечи или бары.

### Нюанс с типами данных
Если вы хотите, чтобы пользователь мог вводить в настройках дробные числа (например, шаг сетки 0.5):
- `Settings.param = 1.0` — будет доступен ввод десятичных знаков.
- `Settings.param = 1` — только целые числа.

### Визуальное отображение
Все пользовательские поля таблицы `Settings` (кроме системных `Name` и `line`) автоматически отображаются в диалоговом окне свойств индикатора в разделе **«Пользовательские настройки»**. Имена полей в таблице становятся названиями строк в интерфейсе.

---

## 7. Доступные функции
Внутри скрипта-индикатора доступны почти все стандартные функции QLua:
- Работа с таблицами (`getItem`, `getNumberOf`, `SearchItems`).
- Торговые функции (`sendTransaction`, `CalcBuySell`).
- Данные и стакан (`getQuoteLevel2`, `getParamEx`).
- Метки (`AddLabel`, `DelLabel`).
- Позиции и лимиты (`getMoney`, `getDepo`, `getFuturesLimit`).
