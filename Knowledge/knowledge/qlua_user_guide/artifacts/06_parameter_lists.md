# Функции для обращения к спискам доступных параметров

## Описание
Эти функции позволяют получать списки кодов классов, информации о конкретных классах и списки инструментов (секций) для указанных классов.

---

### `getClassesList`
```lua
STRING getClassesList()
```
Возвращает **строку**, содержащую коды классов, полученных от сервера за текущий сеанс. Коды разделяются запятой `,` и в конце строки всегда добавляется запятая.

**Пример:**
```lua
local list = getClassesList()
-- list может выглядеть так: "OPTEXP,USDRUB,PSOPT,PSFUT,SPBFUT,"
message("Классы: " .. list)
```

---

### `getClassInfo`
```lua
TABLE getClassInfo(STRING class_code)
```
Возвращает таблицу Lua с подробной информацией о классе `class_code`.

| Поле | Тип | Описание |
|------|-----|----------|
| `firmid` | NUMBER | Код фирмы, которой принадлежит класс |
| `name`   | STRING | Наименование класса |
| `code`   | STRING | Код класса (идентификатор) |
| `npars`  | NUMBER | Количество параметров в классе |
| `nsecs`  | NUMBER | Количество инструментов (секций) в классе |

**Пример:**
```lua
local info = getClassInfo("SPBFUT")
message("Код: " .. info.code .. ", количество секций: " .. info.nsecs)
```

---

### `getClassSecurities`
```lua
STRING getClassSecurities(STRING class_codes)
```
Принимает **строку** с одним или несколькими кодами классов, разделёнными запятыми, и возвращает **строку** с кодами всех инструментов, относящихся к указанным классам. Коды инструментов также разделяются запятой и завершаются запятой.

**Пример:**
```lua
local sec_list = getClassSecurities("SPBFUT")
-- sec_list может выглядеть так:
-- "RSH3,VBZ2,O4Z2,O2Z2,SiM3,SiH3,SiF3,RIH3,RIM3, ... ,"
message("Инструменты: " .. sec_list)
```

---

## Примечания
- Все функции работают **синхронно** и возвращают результаты сразу.
- При работе с большими списками (например, `getClassSecurities` для нескольких классов) рекомендуется разбивать запросы, чтобы не перегружать память скрипта.
- Возврат строк с завершающей запятой упрощает простое `for`‑перебирание через `string.gmatch(list, "([^,]+)")`.
