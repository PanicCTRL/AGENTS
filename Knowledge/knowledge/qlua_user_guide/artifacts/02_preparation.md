# Подготовка к работе

QLua является дополнительным компонентом Рабочего места **QUIK**.

Для работы QLua необходим файл **`qlua.dll`**, который должен находиться в той же папке, что и файлы рабочего места QUIK, например:
```
C:\Program Files\QUIK
```
