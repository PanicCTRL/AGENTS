# Справочник битовых флагов (Bit Flags)

Почти каждая таблица в QUIK содержит поле `flags`. Это число, в битах которого закодированы статусы и параметры объекта. Для проверки флагов в Lua рекомендуется использовать библиотеку `bit` (например, `bit.band(flags, маска)`).

---

## 1. Заявки и Внебиржевые заявки
Применяется к таблицам `orders` и `neg_deals`.

| Бит | Маска | Описание (если установлен) |
|-----|-------|----------------------------|
| 0 | 0x1 | Заявка активна. |
| 1 | 0x2 | Заявка снята. Если бит 0 и бит 1 равны 0 — заявка исполнена. |
| 2 | 0x4 | Заявка на **ПРОДАЖУ**. Если 0 — на покупку. |
| 3 | 0x8 | Заявка лимитированная. Если 0 — рыночная. |
| 4 | 0x10 | Исполнить по разным ценам. |
| 5 | 0x20 | Исполнить немедленно или снять (Fill or Kill). |
| 6 | 0x40 | Заявка маркет-мейкера (или отправлена контрагенту). |
| 7 | 0x80 | Скрытая заявка. |
| 8 | 0x100 | Снять остаток. |
| 9 | 0x200 | Айсберг-заявка. |
| 10 | 0x400 | Отклонена торговой системой. |
| 20 | 0x100000 | В поле `linkedorder` — номер стоп-заявки. |

---

## 2. Сделки и Сделки для исполнения
Применяется к таблицам `trades` и `trades_for_execution`.

| Бит | Маска | Описание (если установлен) |
|-----|-------|----------------------------|
| 0 | 0x1 | Маржинальная сделка. |
| 2 | 0x4 | Сделка на **ПРОДАЖУ**. Если 0 — на покупку. |
| 3 | 0x8 | Сделка по айсберг-заявке. |
| 4 | 0x10 | Сделка отменена. |
| 5 | 0x20 | Пассивная сделка (состояние «П»). |
| 6 | 0x40 | Активная сделка (состояние «А»). |
| 7 | 0x80 | Первая часть свопа. |
| 8 | 0x100 | Вторая часть свопа. |

---

## 3. Обезличенные сделки (All Trades)
| Бит | Маска | Описание (если установлен) |
|-----|-------|----------------------------|
| 0 | 0x1 | Сделка на **ПРОДАЖУ**. |
| 1 | 0x2 | Сделка на **ПОКУПКУ**. |

---

## 4. Стоп-заявки (`stop_orders`)
### Основные флаги
| Бит | Маска | Описание (если установлен) |
|-----|-------|----------------------------|
| 0 | 0x1 | Стоп-заявка активна. |
| 1 | 0x2 | Снята (если 0 и бит 0 равен 0 — исполнена). |
| 2 | 0x4 | На **ПРОДАЖУ**. |
| 3 | 0x8 | Лимитированная. |
| 5 | 0x20 | Ожидает активации. |
| 6 | 0x40 | С другого сервера. |
| 8 | 0x100 | Тейк-профит активирован по частичному исполнению. |
| 9 | 0x200 | Активирована вручную. |
| 10 | 0x400 | Сработала, но отвергнута ТС. |
| 11 | 0x800 | Сработала, но не прошла контроль лимитов. |
| 12 | 0x1000 | Снята из-за снятия связанной заявки. |
| 13 | 0x2000 | Снята из-за исполнения связанной заявки. |
| 15 | 0x8000 | Идет расчет минимума-максимума. |

### Дополнительные флаги
| Бит | Маска | Описание (если установлен) |
|-----|-------|----------------------------|
| 0 | 0x1 | Использовать остаток основной заявки. |
| 1 | 0x2 | При частичном исполнении снять стоп-заявку. |
| 2 | 0x4 | Активировать при частичном исполнении связанной. |
| 3 | 0x8 | Отступ задан в процентах (иначе — в пунктах). |
| 4 | 0x10 | Спред задан в процентах (иначе — в пунктах). |
| 5 | 0x20 | Срок ограничен сегодняшним днем. |
| 6 | 0x40 | Установлен интервал времени действия. |
| 7 | 0x80 | Тейк-профит по рыночной цене. |
| 8 | 0x100 | Исполнение по рыночной цене. |

## 5. Транзакции
| Бит | Маска | Описание (если установлен) |
|-----|-------|----------------------------|
| 20 | 0x100000 | Служебная транзакция. |
| 21 | 0x200000 | Транзакция на выставление заявки. |
