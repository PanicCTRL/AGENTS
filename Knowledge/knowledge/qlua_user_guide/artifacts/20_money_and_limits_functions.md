# Функции получения информации по денежным позициям и лимитам

## getMoney
Функция предназначена для получения информации по денежным позициям. Позволяет узнать текущие балансы, доступные средства и заблокированные лимиты.

**Формат вызова:**
```lua
TABLE res = getMoney(STRING client_code, STRING firmid, STRING tag, STRING currcode)
```

**Параметры:**
- `client_code` — код клиента.
- `firmid` — идентификатор фирмы.
- `tag` — код позиции (группа лимитов).
- `currcode` — код валюты (например, `"SUR"` или `"RUB"`).

**Возвращает таблицу Lua со следующими параметрами:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `money_open_limit` | NUMBER | Входящий лимит по денежным средствам |
| `money_limit_locked_nonmarginal_value` | NUMBER | Стоимость немаржинальных инструментов в заявках на покупку |
| `money_limit_locked` | NUMBER | Заблокированное в заявках на покупку количество денежных средств |
| `money_open_balance` | NUMBER | Входящий остаток по денежным средствам |
| `money_current_limit` | NUMBER | Текущий лимит по денежным средствам |
| `money_current_balance` | NUMBER | Текущий остаток по денежным средствам |
| `money_limit_available` | NUMBER | Доступное количество денежных средств |

## getMoneyEx
Функция предназначена для получения информации по денежным позициям указанного типа (с учетом срока расчетов `limit_kind`, например T+0, T+1, T+2).

**Формат вызова:**
```lua
TABLE res = getMoneyEx(STRING firmid, STRING client_code, STRING tag, STRING currcode, NUMBER limit_kind)
```

**Параметры:**
- `firmid` — идентификатор фирмы.
- `client_code` — код клиента.
- `tag` — код позиции (группа лимитов).
- `currcode` — код валюты.
- `limit_kind` — срок расчётов (0 — T0, 1 — T1, 2 — T2 и т.д.).

**Возвращает таблицу Lua (Позиции по деньгам) со следующими параметрами:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `currcode` | STRING | Код валюты |
| `tag` | STRING | Код позиции |
| `firmid` | STRING | Идентификатор фирмы |
| `client_code` | STRING | Код клиента |
| `openbal` | NUMBER | Входящий остаток |
| `openlimit` | NUMBER | Входящий лимит |
| `currentbal` | NUMBER | Текущий остаток |
| `currentlimit` | NUMBER | Текущий лимит |
| `locked` | NUMBER | Сумма средств, заблокированных под исполнение заявок |
| `locked_value_coef` | NUMBER | Стоимость активов в заявках на покупку немаржинальных инструментов |
| `locked_margin_value` | NUMBER | Стоимость активов в заявках на покупку маржинальных инструментов |
| `leverage` | NUMBER | Плечо |
| `limit_kind` | NUMBER | Срок расчётов (0 — T0, 1 — T1 и т.д.) |
| `wa_position_price` | NUMBER | Средневзвешенная цена приобретения позиции |
| `orders_collateral` | NUMBER | Гарантийное обеспечение заявок |
| `positions_collateral` | NUMBER | Гарантийное обеспечение позиций |

> В случае ошибки (или отсутствия позиции) функция возвращает `nil`.

## getDepoEx
Функция предназначена для получения позиций по инструментам (бумагам) указанного типа (с учетом срока расчетов `limit_kind`).

**Формат вызова:**
```lua
TABLE res = getDepoEx(STRING firmid, STRING client_code, STRING sec_code, STRING trdaccid, NUMBER limit_kind)
```

**Параметры:**
- `firmid` — идентификатор фирмы.
- `client_code` — код клиента.
- `sec_code` — код инструмента.
- `trdaccid` — счет депо (торговый счет).
- `limit_kind` — срок расчётов (0 — T0, 1 — T1, 2 — T2 и т.д.).

**Возвращает таблицу Lua (Позиции по инструментам) со следующими параметрами:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `sec_code` | STRING | Код инструмента |
| `trdaccid` | STRING | Счет депо |
| `firmid` | STRING | Идентификатор фирмы |
| `client_code` | STRING | Код клиента |
| `openbal` | NUMBER | Входящий остаток (штук) |
| `openlimit` | NUMBER | Входящий лимит |
| `currentbal` | NUMBER | Текущий остаток |
| `currentlimit` | NUMBER | Текущий лимит |
| `locked_sell` | NUMBER | В продаже. Количество инструментов, заблокированное под заявки на продажу |
| `locked_buy` | NUMBER | В покупке. Количество инструментов в заявках на покупку |
| `locked_buy_value` | NUMBER | Стоимость инструментов, заблокированных под покупку |
| `locked_sell_value` | NUMBER | Стоимость инструментов, заблокированных под продажу |
| `wa_position_price` | NUMBER | Цена приобретения |
| `wa_price_currency` | STRING | Валюта цены приобретения (например, `"%"` для облигаций) |
| `limit_kind` | NUMBER | Срок расчётов (0 — T0, 1 — T1 и т.д.) |

> В случае ошибки (или отсутствия позиции) функция возвращает `nil`.

## getFuturesLimit
Функция предназначена для получения информации по фьючерсным лимитам (гарантийному обеспечению, вариационной марже и общему балансу на срочном рынке).

**Формат вызова:**
```lua
TABLE res = getFuturesLimit(STRING firmid, STRING trdaccid, NUMBER limit_type, STRING currcode)
```

**Параметры:**
- `firmid` — идентификатор фирмы.
- `trdaccid` — торговый счет срочного рынка (ФОРТС).
- `limit_type` — тип лимита (0 — Денежные средства, 1 — Залоговые денежные средства и т.д.).
- `currcode` — код валюты (если нужен лимит без привязки к валюте, передается пустая строка `""`).

**Возвращает таблицу Lua (Ограничения по клиентским счетам) со следующими параметрами:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `firmid` | STRING | Идентификатор фирмы |
| `trdaccid` | STRING | Торговый счет |
| `limit_type` | NUMBER | Тип лимита (0..7) |
| `liquidity_coef` | NUMBER | Коэффициент ликвидности |
| `cbp_prev_limit` | NUMBER | Предыдущий лимит открытых позиций |
| `cbplimit` | NUMBER | Лимит открытых позиций (доступные средства) |
| `cbplused` | NUMBER | Текущие чистые позиции (ГО всего) |
| `cbplplanned` | NUMBER | Плановые чистые позиции |
| `varmargin` | NUMBER | Вариационная маржа (текущая) |
| `accruedint` | NUMBER | Накопленный доход |
| `cbplused_for_orders` | NUMBER | Заблокировано под заявки (ГО под заявки) |
| `cbplused_for_positions` | NUMBER | Заблокировано под позиции (ГО под позиции) |
| `options_premium` | NUMBER | Премия по опционам |
| `ts_comission` | NUMBER | Биржевые сборы |
| `kgo` | NUMBER | Коэффициент клиентского гарантийного обеспечения |
| `currcode` | STRING | Валюта лимита |
| `real_varmargin` | NUMBER | Реально начисленная в ходе клиринга вариационная маржа |
| `risk_level` | NUMBER | Уровень риска клиента (0 - нет, 1 - КНУР, 2 - КСУР, 3 - КПУР, 4 - КОУР) |
| `go_without_orders` | NUMBER | ГО без учета заявок |
| `go_planned` | NUMBER | Плановое ГО |
| `indicative_varmargin`| NUMBER | Индикативная вариационная маржа |

> В случае ошибки функция возвращает `nil`.

## getFuturesHolding
Функция предназначена для получения информации по позициям конкретных фьючерсных контрактов (сколько куплено/продано, текущая маржа по инструменту).

**Формат вызова:**
```lua
TABLE res = getFuturesHolding(STRING firmid, STRING trdaccid, STRING sec_code, NUMBER type)
```

**Параметры:**
- `firmid` — идентификатор фирмы.
- `trdaccid` — торговый счет.
- `sec_code` — код фьючерсного контракта (например, `"RIM3"`).
- `type` — тип лимита (обычно `0` - не определен, или `1` - основной счет, `2` - клиентские счета).

**Возвращает таблицу Lua (Позиции по клиентским счетам - фьючерсы) со следующими параметрами:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `firmid` | STRING | Идентификатор фирмы |
| `trdaccid` | STRING | Торговый счет |
| `sec_code` | STRING | Код фьючерсного контракта |
| `type` | NUMBER | Тип лимита (0, 1, 2, 4) |
| `startbuy` | NUMBER | Входящие длинные позиции (штук) |
| `startsell` | NUMBER | Входящие короткие позиции (штук) |
| `startnet` | NUMBER | Входящие чистые позиции |
| `todaybuy` | NUMBER | Текущие длинные позиции |
| `todaysell` | NUMBER | Текущие короткие позиции |
| `totalnet` | NUMBER | Текущие чистые позиции (итоговая позиция: >0 лонг, <0 шорт) |
| `openbuys` | NUMBER | Активные заявки на покупку |
| `opensells` | NUMBER | Активные заявки на продажу |
| `cbplused` | NUMBER | Оценка текущих чистых позиций (заблокировано ГО) |
| `cbplplanned` | NUMBER | Плановые чистые позиции |
| `varmargin` | NUMBER | Вариационная маржа по данному инструменту |
| `avrposnprice` | NUMBER | Эффективная (средняя) цена позиций |
| `positionvalue`| NUMBER | Стоимость позиций |
| `real_varmargin`| NUMBER | Реально начисленная в клиринг вариационная маржа |
| `total_varmargin`| NUMBER| Суммарная вариационная маржа по итогам основного клиринга |
| `session_status`| NUMBER | Статус торговой сессии (1 - основная, 2-3 - промклиринг, 4-6 - основной клиринг, 7 - вечерняя) |

> В случае ошибки функция возвращает `nil`.
