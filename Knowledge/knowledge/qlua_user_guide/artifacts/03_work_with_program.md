# Работа с программой

## Доступ к функциям QLua

После установки компонента в главном меню QUIK появляется пункт **Сервисы → Lua скрипты**.

## Форма «Доступные скрипты»

Эта форма используется для **добавления, удаления, перезагрузки и запуска** пользовательских Lua‑скриптов.

### Кнопки окна
- **Добавить** – загрузить новый скрипт из файла.
- **Удалить** – удалить выбранный скрипт.
- **Выделить все** – выделить все скрипты в списке.
- **Запустить** – запустить выбранные скрипты, выбрав версию Lua‑машины:
  - *Запустить в Lua 5.4.1*
  - *Запустить в Lua 5.3.5*
- **Остановить** – остановить выполнение выбранного скрипта.

#### Выбор версии Lua по умолчанию
- При нажатии **Запустить** по умолчанию используется **Lua 5.4.1**.
- Значение можно изменить в настройках QUIK: **«Lua скрипты» → «Версия Lua для скриптов пользователей»** (см. пункт 2.10.7 раздела 2 «Основные принципы работы»).

### Состояние кнопок
- Кнопки **Запустить** и **Остановить** активны только в зависимости от текущего состояния скрипта.

### Автоматический запуск после перезапуска терминала
- Скрипты, которые были запущены перед закрытием терминала, автоматически стартуют после его перезапуска.

## Память скриптов
- Столбец **«Память, KB»** показывает сумму значений, возвращаемых функциями `lua_gc(LUA_GCCOUNT)` и `lua_gc(LUA_GCCOUNTB)`.
- Внутри скрипта можно получить используемую память через стандартную Lua‑функцию:
  ```lua
  collectgarbage("count")
  ```

## Ошибки исполнения
- Ошибки скриптов выводятся в специальную область окна.
