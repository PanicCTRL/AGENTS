# О программе

**QLua** — интерпретатор языка Lua, встроенный в платформу **QUIK**. Он предоставляет скриптам, написанным на Lua, возможность взаимодействовать с рабочим местом QUIK.

- **База**: библиотека `qlua.dll` (64‑бит), доступ к внутренним данным QUIK и возможность отправки клиентских транзакций на сервер.
- **Асинхронность**: в отличие от QPILE, QLua поддерживает асинхронную обработку данных через **callback‑функции**.
- **События, генерируемые QUIK**:
  1. получение новых данных;
  2. подключение к серверу;
  3. отключение от сервера;
  4. остановка выполнения скрипта;
  5. закрытие рабочего места.
  Каждый из этих событий может вызвать соответствующий callback в скрипте.
- **Расширяемость**: в скрипт можно загрузить сторонние библиотеки (DLL). Требования:
  - использовать 64‑разрядные версии библиотек;
  - неправильная работа сторонних библиотек может привести к ошибкам терминала QUIK.

> Подробнее о самом языке Lua – <https://www.lua.org>
