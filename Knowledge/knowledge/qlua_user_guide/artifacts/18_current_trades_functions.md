# Функции получения значений таблицы «Текущие торги»

Эти функции используются для мгновенного получения текущих рыночных параметров (цена последней сделки, лучший спрос/предложение, оборот и т.д.) по заданному инструменту.

---

## Важные особенности работы (Обязательно к прочтению)
Чтобы функции `getParamEx` и `getParamEx2` возвращали **актуальные**, а не пустые значения, терминал QUIK должен получать эти данные с сервера. Это зависит от настроек (`Система` -> `Настройки` -> `Основные настройки...` -> `Программа` -> `Получение данных` -> `Котировки`).

Варианты получения данных:
1. **Вручную**: Включен режим «по выбранным классам», и нужные параметры заказаны вручную.
2. **Через открытую таблицу**: Включен режим «"умный" заказ данных», и у вас открыта визуальная Таблица текущих торгов с нужными колонками.
3. **Автоматически из кода**: Включен режим «"умный" заказ данных», и вы программно заказали параметры через функцию `ParamRequest` (или `CreateDataSource`).

> **Примечание:** QUIK автоматически заказывает параметры, необходимые для расчета позиций, если включен «умный» заказ данных.

---

## getParamEx
Получает значение параметра биржевой информации.

**Формат вызова:**
```lua
TABLE res = getParamEx(STRING class_code, STRING sec_code, STRING param_name)
```

**Возвращает таблицу со следующими полями:**

| Поле | Тип | Описание |
|------|-----|----------|
| `result` | STRING | `"1"` — параметр найден, `"0"` — ошибка (параметр не найден). |
| `param_type` | STRING | Тип данных: `1`‑DOUBLE, `2`‑LONG, `3`‑CHAR, `4`‑ENUM, `5`‑TIME, `6`‑DATE. |
| `param_value`| STRING | Числовое значение параметра (строкой). Для типа 3 всегда `"0"`. |
| `param_image`| STRING | Отформатированное строковое значение (как в таблице терминала), с разделителями разрядов или текстовым значением для перечислений. |

---

## getParamEx2
Улучшенная версия `getParamEx`. Работает абсолютно так же и возвращает такую же таблицу, но имеет одно критическое отличие:

Она **совместима с функцией `CancelParamRequest`**. Если вы заказали данные через `ParamRequest`, а затем хотите остановить их получение (чтобы не нагружать канал), вы должны получать данные именно через `getParamEx2`. Если использовать обычный `getParamEx`, отмена заказа не сработает.

**Формат вызова:**
```lua
TABLE res = getParamEx2(STRING class_code, STRING sec_code, STRING param_name)
```
