# Функции для заказа стакана котировок (Level II)

Эти функции управляют подпиской на получение данных о «стакане» (очереди заявок) по конкретным инструментам. Подписка необходима для того, чтобы терминал начал получать изменения стакана и транслировать их в функцию обратного вызова `OnQuote`.

---

## Subscribe_Level_II_Quotes
Заказывает получение стакана с сервера.

**Формат вызова:**
```lua
BOOLEAN res = Subscribe_Level_II_Quotes(class_code, sec_code)
```

**Параметры:**
- `class_code` — код класса инструмента.
- `sec_code` — код инструмента.

**Возврат:** `true` при успешном заказе.

---

## Unsubscribe_Level_II_Quotes
Отменяет заказ на получение стакана.

**Формат вызова:**
```lua
BOOLEAN res = Unsubscribe_Level_II_Quotes(class_code, sec_code)
```

**Параметры:**
- `class_code` — код класса.
- `sec_code` — код инструмента.

**Возврат:** `true` при успешной отмене подписки.

---

## IsSubscribed_Level_II_Quotes
Проверяет, заказан ли стакан по данному инструменту.

**Формат вызова:**
```lua
BOOLEAN res = IsSubscribed_Level_II_Quotes(class_code, sec_code)
```

**Параметры:**
- `class_code` — код класса.
- `sec_code` — код инструмента.

**Возврат:** `true`, если подписка активна.
