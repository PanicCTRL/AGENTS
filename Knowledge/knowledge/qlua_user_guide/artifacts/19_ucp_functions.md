# Функции получения информации по Единой Денежной Позиции (ЕДП)

Эти функции предназначены для кросс-маржинальной торговли (Единая Денежная Позиция / UCP). Они позволяют связывать счета фондового рынка с торговыми счетами срочного рынка для клиентов, использующих единый счет.

---

## isUcpClient
Проверяет, подключена ли у клиента Единая Денежная Позиция.

**Формат вызова:**
```lua
BOOLEAN res = isUcpClient(STRING firmid, STRING client)
```

**Параметры:**
- `firmid` — идентификатор фирмы фондового рынка (например, `"MC0000000000"`).
- `client` — код клиента фондового рынка или торговый счет срочного рынка.

**Возврат:** `true`, если клиент использует ЕДП, иначе `false`.

---

## getTrdAccByClientCode
Возвращает торговый счет срочного рынка (ФОРТС), привязанный к коду клиента фондового рынка с ЕДП.

**Формат вызова:**
```lua
STRING trdaccid = getTrdAccByClientCode(STRING firmid, STRING client_code)
```

**Параметры:**
- `firmid` — идентификатор фирмы фондового рынка.
- `client_code` — код клиента на фондовом рынке.

**Возврат:** Строка с торговым счетом срочного рынка. Если ЕДП нет, возвращает `nil`.

---

## getTrdAccByClientCodeEx
Возвращает все торговые счета срочного рынка, привязанные к клиенту с ЕДП.

**Формат вызова:**
```lua
TABLE accounts = getTrdAccByClientCodeEx(STRING firmid, STRING client_code)
```

**Возврат:** 
- Таблица (массив) строк с торговыми счетами.
- Если счетов нет, возвращает пустую таблицу `{}`.
- Если произошла ошибка получения данных, возвращает `nil`.

---

## getClientCodeByTrdAcc
Обратная функция: возвращает код клиента фондового рынка по торговому счету срочного рынка.

**Формат вызова:**
```lua
STRING client_code = getClientCodeByTrdAcc(STRING firmid, STRING trdaccid)
```

**Параметры:**
- `firmid` — идентификатор фирмы фондового рынка.
- `trdaccid` — торговый счет срочного рынка.

**Возврат:** Строка с кодом клиента фондового рынка. Если ЕДП нет, возвращает `nil`.
