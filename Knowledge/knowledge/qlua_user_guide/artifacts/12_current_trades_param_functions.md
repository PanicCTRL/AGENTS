# Функции заказа параметров Таблицы текущих торгов

Эти функции позволяют скрипту динамически управлять списком получаемых от сервера параметров для конкретных инструментов. Это полезно для снижения нагрузки на канал связи, если вам нужны данные по большому количеству тикеров, но не по всем параметрам сразу.

---

## Важное требование
Для корректной работы функций в настройках терминала QUIK должен быть включен **режим «"умный" заказ данных»**:
`Система` -> `Настройки` -> `Основные настройки...` -> `Программа` -> `Получение данных` -> `Котировки`.

---

## ParamRequest
Заказывает получение конкретного параметра для инструмента.

**Формат вызова:**
```lua
BOOLEAN res = ParamRequest(STRING class_code, STRING sec_code, STRING db_name)
```

**Параметры:**
- `class_code` — код класса.
- `sec_code` — код инструмента.
- `db_name` — идентификатор параметра (например, "LAST", "BID", "VOLTODAY").

**Возврат:** `true` при успешном заказе.

---

## CancelParamRequest
Отменяет заказ на получение параметра.

**Формат вызова:**
```lua
BOOLEAN res = CancelParamRequest(STRING class_code, STRING sec_code, STRING db_name)
```

**Особенности работы:**
- **Связь с функциями получения:** Отмена заказа сработает только в том случае, если в скрипте для этого параметра используется функция `getParamEx2()`. 
- **Ограничение:** Если используется функция `getParamEx()`, вызов `CancelParamRequest()` будет проигнорирован, и данные продолжат поступать.
