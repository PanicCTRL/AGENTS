# Приложения: Практические примеры и паттерны

В этом разделе собраны примеры кода, демонстрирующие лучшие практики разработки на QLua.

---

## 1. Объектно-ориентированная обертка для таблиц (QTable)
Паттерн из Приложения 1 позволяет работать с таблицами QUIK как с объектами.

```lua
-- Пример использования обертки
t = QTable.new()
t:AddColumn("Тикер", QTABLE_CACHED_STRING_TYPE, 10)
t:AddColumn("Цена", QTABLE_DOUBLE_TYPE, 10)
t:SetCaption("Мой Монитор")
t:Show()

local row = t:AddLine()
t:SetValue(row, "Тикер", "SBER")
t:SetValue(row, "Цена", 250.45)
```

**Ключевая логика обертки:**
- Использует `metatable` для связки методов.
- Хранит `t_id` внутри объекта.
- Автоматически обрабатывает форматирование через функции-коллбэки.

## 2. Обработка событий мыши и клавиатуры
Пример настройки уведомлений о кликах по таблице:

```lua
-- Коллбэк для обработки событий
function event_callback(t_id, msg, par1, par2)
    if msg == QTABLE_LBUTTONDOWN then
        -- par1 = строка, par2 = столбец
        message("Нажата ячейка: " .. par1 .. ":" .. par2)
    elseif msg == QTABLE_CLOSE then
        message("Таблица закрыта")
    end
end

-- Регистрация коллбэка
SetTableNotificationCallback(t_id, event_callback)
```

## 3. Оптимизация SearchItems
Приложение 4 раскрывает, как ускорить поиск в «тяжелых» таблицах (например, Обезличенные сделки).

**Вариант 1: Медленный (передается вся таблица)**
```lua
t1 = SearchItems("all_trades", 0, count-1, function(t) return t.qty > 100 end)
```

**Вариант 2: Быстрый (передаются только нужные поля)**
```lua
-- par1 будет равен qty, par2 - class_code
function fn(par1, par2)
    return par1 > 100 and par2 == "SPBFUT"
end
t1 = SearchItems("all_trades", 0, count-1, fn, "qty, class_code")
```
*Примечание: Если поле вложено (например, время), используйте точку: `"datetime.hour, datetime.min"`.*

## 4. Жизненный цикл интерактивного скрипта
Шаблон для скриптов, которые должны реагировать на действия пользователя и корректно завершаться:

```lua
stopped = false

function OnStop()
    stopped = true
end

function main()
    -- Инициализация (создание таблиц, подписки)
    while not stopped do
        -- Основная логика робота
        sleep(100) -- Обязательная пауза, чтобы не вешать терминал
    end
    -- Финализация (закрытие файлов, очистка)
end
```
