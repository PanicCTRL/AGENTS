# Функции обратного вызова

> **Важно:** функции вызываются в основном потоке терминала QUIK, поэтому их код должен быть максимально эффективным.

## Общий список колбэков
| Callback | Описание |
|---|---|
| `OnInit(script_path)` | Вызывается перед `main()`. Принимает полный путь к скрипту. Инициализирует переменные и библиотеки. |
| `main()` | Главный поток выполнения скрипта. Создаётся отдельный поток. Скрипт считается работающим, пока работает `main()`. |
| `OnStop(flag)` | Остановка скрипта из диалога управления или при закрытии терминала. `flag=1` – пользователь остановил, `flag=2` – закрытие терминала. Возвращает таймаут (мс) или **nil** (по умолчанию 5 с). |
| `OnClose()` | Вызывается перед закрытием терминала QUIK и при выгрузке `qlua.dll`. |
| `OnCleanUp()` | Вызывается при смене сервера, пользователя либо торговой сессии. Может вызываться несколько раз за одну смену. |
| `OnConnected(flag)` | Установлено соединение с сервером QUIK; `flag` – **false**, если получено новое описание класса в течение дня. |
| `OnDisconnected()` | Отключение от сервера QUIK. |
| `OnQuote(class_code, sec_code)` | Получено изменение стакана котировок. |
| `OnParam(class_code, sec_code)` | Изменились параметры инструмента. |
| `OnTransReply(trans_reply)` | Получен ответ на транзакцию, отправленную из любого скрипта. |
| `OnAccountBalance(acc_bal)` | Изменения позиции по счету. |
| `OnAccountPosition(acc_pos)` | Изменения позиции участника по денежным средствам. |
| `OnAllTrade(alltrade)` | Получена обезличенная сделка. |
| `OnTrade(trade)` | Получена или изменена обычная сделка. |
| `OnOrder(order)` | Получена или изменена заявка. |
| `OnStopOrder(stop_order)` | Получена или изменена стоп‑заявка. |
| `OnNegDeal(neg_deals)` | Получена внебиржевая заявка/изменение. |
| `OnNegTrade(neg_trade)` | Получена или изменена внебиржевая сделка. |
| `OnMoneyLimit(mlimit)` | Изменения денежной позиции. |
| `OnMoneyLimitDelete(mlimit_del)` | Удаление денежной позиции. |
| `OnDepoLimit(dlimit)` | Изменения позиции по инструментам. |
| `OnDepoLimitDelete(dlimit_del)` | Удаление позиции по инструментам. |
| `OnFuturesClientHolding(fut_pos)` | Изменения позиции на срочном рынке. |
| `OnFuturesLimitChange(fut_limit)` | Изменения ограничений на срочном рынке. |
| `OnFuturesLimitDelete(lim_del)` | Удаление лимита на срочном рынке. |
| `OnMoneyLimitDelete(mlimit_del)` | Удаление денежной позиции. |
| `OnFirm(firm)` | Получено описание новой фирмы. |
| `OnQuote(class_code, sec_code)` | Изменение стакана котировок. |
| `OnParam(class_code, sec_code)` | Изменение текущих параметров инструмента. |

## Примеры колбэков
```lua
function OnInit(script_path)
    -- инициализация переменных, подключение внешних библиотек
    message("Инициализация: " .. script_path)
end

function OnQuote(class_code, sec_code)
    local q = getQuoteLevel2(class_code, sec_code)
    if q and q.bid > 130000 then
        message("Спрос вырос: " .. q.bid)
    end
end

function OnStop(flag)
    -- задаём 3‑секундный таймаут перед принудительным завершением
    return 3000
end
```

## Параметры таблиц
Все функции‑callback получают **TABLE**‑объекты Lua, где каждый элемент – поле с параметром. Пример структуры `order` (для `OnOrder`):
```lua
order = {
    trans_id = 12345,    -- номер транзакции
    class_code = "SPBFUT",
    sec_code = "RIZ2",
    operation = "B",    -- B – покупка, S – продажа
    price = 130500,
    qty = 2,
    state = "ACTIVE"    -- состояние заявки
}
```

> **Совет:** при работе с большими массивами данных (например, `OnAllTrade`) используйте `collectgarbage("collect")` для освобождения памяти.
