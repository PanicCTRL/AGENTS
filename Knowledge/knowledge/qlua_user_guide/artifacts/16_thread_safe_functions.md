# Потокобезопасные функции для работы с таблицами

В терминале QUIK функция `main()` и функции обратного вызова (Callbacks) выполняются в разных потоках. Одновременный доступ к одной и той же таблице Lua из разных потоков может привести к ошибкам или аварийному завершению скрипта.

Для решения этой проблемы `qlua.dll` предоставляет потокобезопасные аналоги стандартных функций Lua.

---

## Принцип работы
Выполнение потокобезопасной функции блокирует доступ к таблице из других потоков до момента завершения текущей операции. Это гарантирует целостность данных.

Формат вызова функций полностью совпадает с их стандартными аналогами из библиотеки `table`.

---

## Таблица соответствия функций

| Стандартная функция Lua | Потокобезопасный аналог | Описание |
|-------------------------|--------------------------|----------|
| `table.concat`          | **`sconcat`**            | Объединение элементов таблицы в строку. |
| `table.insert`          | **`sinsert`**            | Вставка элемента в таблицу. |
| `table.remove`          | **`sremove`**            | Удаление элемента из таблицы. |
| `table.sort`            | **`ssort`**              | Сортировка таблицы. |

---

## Пример использования
Если у вас есть глобальная таблица `orders_log`, в которую пишут и `main`, и `OnOrder`:

```lua
-- В любом потоке
sinsert(orders_log, order_data) -- Безопасно
```

> **Примечание:** Эти функции являются глобальными и не требуют приставки `table.`.
