# Библиотека bit для работы с битовыми масками

В QLua встроена библиотека `bit`, которая позволяет выполнять логические операции на уровне отдельных битов числа. Это необходимо для расшифровки поля `flags` в таблицах QUIK.

---

## bit.test
Проверяет состояние конкретного бита.

**Формат вызова:**
```lua
BOOLEAN res = bit.test(NUMBER x, NUMBER n)
```
- `x` — проверяемое значение (флаги).
- `n` — номер бита (**нумерация начинается с 0**).

**Возврат:** `true`, если бит равен 1, и `false`, если 0.

---

## bit.band
Битовое **И** (AND).

**Формат вызова:**
```lua
NUMBER res = bit.band(x1, x2, ...)
```
Возвращает результат пересечения битов всех аргументов. Часто используется для наложения маски.

---

## bit.bor
Битовое **ИЛИ** (OR).

**Формат вызова:**
```lua
NUMBER res = bit.bor(x1, x2, ...)
```
Объединяет биты всех аргументов. Используется для установки нескольких флагов одновременно.

---

## bit.bxor
Битовое **Исключающее ИЛИ** (XOR).

**Формат вызова:**
```lua
NUMBER res = bit.bxor(x1, x2, ...)
```
Инвертирует биты (0 становится 1, если во втором аргументе 1).

---

## bit.bnot
Битовое **НЕ** (NOT).

**Формат вызова:**
```lua
NUMBER res = bit.bnot(x)
```
Инвертирует все биты числа.

---

## bit.tohex
Преобразование в шестнадцатеричную строку.

**Формат вызова:**
```lua
STRING hex = bit.tohex(NUMBER x [, NUMBER n])
```
- `x` — число.
- `n` — количество знаков в строке (необязательно).

Удобно для логирования флагов в понятном виде (например, `0x104`).
